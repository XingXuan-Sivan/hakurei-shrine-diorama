# 实施计划：交互 + 拉门 + 性能

对应 spec：`docs/superpowers/specs/2026-10-18-interactions-design.md`

## 任务

1. **T1 点按通道** — 新增 `src/interaction.js`：指针判定、raycast 注册表、悬停光标、双击复位。接入 `src/main.js`。
   - 验收：点击空白不误触；拖动旋转相机不触发点击。
2. **T2 门区重建** — `src/scene/shrine.js`：壁裙拆两段、门扇后移 0.20/0.34、薄型 shoji、敷居/鴨居/内法框/戸袋口、内饰后移 0.25、`setDoor()` + 补间。
   - 验收：23 帧行程 AABB 无相交；关/半开/全开三态截图。
3. **T3 灵梦** — `character.poke()` + 气泡 DOM + 12 条台词。
4. **T4 赛钱箱** — 硬币抛物 + `src/audio.js` 合成音。
5. **T5 御神签** — `src/omikuji.js` 相机子节点纸签 + canvas 签文 + 收回。
6. **T6 样式** — 气泡与光标样式进 `styles.css`，不新增常驻 UI。
7. **T7 视觉验收** — 3 机位 × 3 门态 + 夜间 + 窄屏截图，逐张确认。
8. **T8 性能** — 基线测量 → 无损优化 → 对比表；不达标回退。

## 顺序

T1 → T2 → T7（门态截图）→ T3 → T4 → T5 → T6 → T7（全量）→ T8

## 风险点

- 门的 Z 向间隙只有 0.03，改任何一处都要重跑 AABB。
- 内饰后移会改变开门视角的空旷感，以截图为准。
- 相机子节点纸签在窄屏要缩到 38% 屏高。
